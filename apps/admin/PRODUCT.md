# OPC Admin

A single administrator uses this desktop-first web application to maintain the articles, categories, tags, and topics of a technical website. The public Astro site is a separate surface and retains its existing identity and routes.

The sign-in surface is in Operate mode. It should get the administrator into their workspace without ceremony, support keyboard use and password managers, work on a narrow screen, and explain failures without identifying valid accounts.

Source: first-stage implementation brief. Assumption: the initial admin interface uses Chinese surrounding copy and the requested English field names. No registration, password recovery, or future modules are exposed.
